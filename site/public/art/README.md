# art/

The page looks here for the show's pieces. Nothing ships; every `<img>` on the
page falls back to a CSS gradient when its file is missing, so the lab runs
without art.

Generate the set with `python art/gen.py` (Nano Banana; see that file for the
key, the STYLE note and the PIECES dict), then drop the JPEGs here:

    hero.jpg       16:9 · the cover and the README
    greeter.jpg    1:1  · the agent's portrait on the stage
    lamp.jpg       1:1  · optional, the rail

CHANGE ME (the show): the file names are referenced in site/lib/chapters.ts (ART).
